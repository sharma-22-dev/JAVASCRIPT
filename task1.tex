What is a variable in JavaScript?
Answer: A variable is a named container used to store a value or data.

What are the three keywords used to create variables?
Answer: The three keywords are var, let, and const.

Write the syntax to create a variable using var.
Answer: var variableName = value;

Write the syntax to create a variable using let.
Answer: let variableName = value;

Write the syntax to create a variable using const.
Answer: const variableName = value;

What is declaration?
Answer: Declaration means creating a variable without assigning a value to it.

What is initialization?
Answer: Initialization means assigning the first value to a variable.


What is reassignment?
Answer: Reassignment means changing the value of an existing variable.


What is redeclaration?
Answer: Redeclaration means declaring the same variable again in the same scope.

Example: var x = 10; var x = 20;

Which keyword allows redeclaration?
Answer: var allows redeclaration in the same scope.

Which keyword allows reassignment?
Answer: var and let allow reassignment.

Which keyword requires initialization when declared?
Answer: const requires initialization when it is declared.

Identify the declaration and initialization: let age = 25;
Answer: Declaration: let age
Initialization: = 25

Can a let variable be reassigned?
Answer: Yes, a let variable can be reassigned.

Can a let variable be redeclared?
Answer: No, a let variable cannot be redeclared in the same scope.

CONST

Create a const variable called pi with the value 3.14.
Answer: const pi = 3.14;

Can a const variable be reassigned?
Answer: No, a const variable cannot be reassigned.

Can a const variable be redeclared?
Answer: No, a const variable cannot be redeclared in the same scope.

What is wrong with this code?
const age;
age = 25;
Answer: A const variable must be initialized when it is declared. You cannot declare a const variable without giving it a value.


What happens here?

Answer: It produces an error because a const variable cannot be reassigned.

Answer: 100

Which keyword should you use if the value should not be reassigned?
Answer: const

What is the difference between let and const?
Answer: let can be reassigned, but const cannot be reassigned. Also, a const variable must be initialized when it is declared.

What is the difference between var and const?
Answer: var can be redeclared and reassigned, while const cannot be redeclared or reassigned. Also, const must be initialized when declared.
